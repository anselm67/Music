scripts/

One-off diagnostic and migration tools. Run via uv run python scripts/<name>.py from the repo root. Not part of the installable package and not type-checked under mypy.

eval_predicted_boxes.py diagnostic staffer noter

Pre-merge jitter diagnostic. Measures how much noter's transcription degrades when fed staffer's predicted stave crops instead of ground-truth crops. Reports token-similarity drop, matched-box error (Δtop/Δbottom px), and detection miss/extra rates — i.e. the spec for noter's box-jitter augmentation. Supports both PDMX and KernSheet sources.

Usage
# PDMX
uv run python scripts/eval_predicted_boxes.py \
    --noter enhanced3 --staffer stave-primary-grid \
    --csv System2.csv --pages 300 --device cuda

# KernSheet (real-scan jitter spec)
uv run python scripts/eval_predicted_boxes.py \
    --kern-home /home/anselm/datasets/KernSheet \
    --noter enhanced3-kernsheet --staffer stave-primary-grid-full-kernsheet \
    --pages 300 --device cuda
imslp_predict.py demo scorer

End-to-end demo on a real IMSLP score. Downloads a PDF (direct URL or local file), rasterises every page to PNG via pdftoppm, then runs scorer predict. Handles the IMSLP disclaimer cookie automatically.

Usage
uv run python scripts/imslp_predict.py <url|file.pdf> [--dpi 300] [--model ravel] [--pages N]
Notes

Requires pdftoppm (poppler). Pass --pages N to limit to the first N pages. The default model is ravel.

kernsheet_pages_to_1based.py migration kernsheet

One-time migration: bumps every page_number in KernSheet layout/*.json files from 0-based to 1-based (matching the PDMX/staffer convention of pages[page_number - 1]). Also drops the stale 0-based PNG cache so images re-render under the new naming. Idempotent — scores already at 1-based are skipped.

Usage
uv run python scripts/kernsheet_pages_to_1based.py
migrate_bars_to_system.py migration pdmx kernsheet

Moves bars[] (barline x-coordinates) from each Staff up to the parent System in layout JSON files. Since all staves in a system share the same bars, storing it once on the system avoids redundancy. Default is a dry-run; pass --write to modify files in place. Migrates both PDMX (~253k files) and KernSheet (~581 files) in parallel.

Usage
uv run python scripts/migrate_bars_to_system.py           # dry-run
uv run python scripts/migrate_bars_to_system.py --write   # write in-place
migrate_kernsheet_layout.py migration kernsheet

Thin shim around kernsheet.migrate.migrate (also exposed as kernsheet migrate CLI). Migrates KernSheet layout files to the current schema. Default is a dry-run.

Usage
uv run python scripts/migrate_kernsheet_layout.py [--home DIR] [--limit N] [--write]
migrate_layout_id.py migration pdmx

Rewrites the id field in every PDMX build/layout/*.json from the old absolute MXL path to the home-relative key (mxl/<...>.mxl). Safe to run during a live training — only the unused id field changes, and writes are atomic (os.replace). Dry-run by default.

Usage
uv run python scripts/migrate_layout_id.py [--home DIR] [--dry-run] [--limit N]
scorer_error_mix.py diagnostic scorer

Settles the "spellcheck layer" design question with a number. For each predicted stave it runs a Levenshtein backtrace and tallies substitutions (wrong token — a position-wise refiner can fix these) vs. insertions/deletions (structural length changes — a fixed-length spellcheck layer cannot fix these). Also reports whether the predicted spines in a multi-stave system agree on the number of barline (=) records vs. GT.

Usage
uv run python scripts/scorer_error_mix.py ravel -n 300
uv run python scripts/scorer_error_mix.py merge1 -n 300 --pdmx-home <PDMX>
smoke_kernsheet.py smoke test kernsheet

Smoke test for the KernSheet data plumbing. Runs a tiny number of training steps (2 optimiser steps) through staffer, noter, and scorer on KernSheetSource to confirm the full pipeline (source → dataset → datamodule → model forward+backward) doesn't crash. Not a real training run — weights are garbage, the goal is only to exercise the plumbing end-to-end.

Usage
uv run python scripts/smoke_kernsheet.py
staffer_box_deltas.py diagnostic staffer

Per-dimension box delta diagnostic. For each matched stave pair (predicted vs. GT, Hungarian-matched), reports Δleft, Δright, Δtop, Δbottom (pred − GT, pixels) with signed mean (bias direction) and absolute statistics (error magnitude). Supports both PDMX and KernSheet sources.

Usage
# PDMX
uv run python scripts/staffer_box_deltas.py --staffer stave-primary-grid-full

# KernSheet
uv run python scripts/staffer_box_deltas.py \
    --staffer stave-primary-grid-full-kernsheet \
    --kern-home /home/anselm/datasets/KernSheet
