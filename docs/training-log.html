enhanced2-vflip

2026-05-28 · tag: train/enhanced2-vflip · 12 epochs

Hypothesis: the top→bottom cy drift in enhanced2 is caused by a training distribution bias (top staves appear more often). Adding vertical flip augmentation (p=0.5) should force the model to generalise symmetrically.

Changes from enhanced2

+ Vertical flip augmentation — p=0.5 (image + GT box mirroring)

Architecture

Identical to enhanced2 — same N=16/M=16 queries, same group attention.

flat

2026-05-28 · tag: train/flat · 12 epochs   training in progress

New architecture: stave queries become a flat global pool attending directly to image memory, rather than being conditioned on system queries via group attention. Each stave self-assigns to a system through the assign head. System query count reduced from 16 to 10 (covers 99.1% of pages in Staff16).

Changes from enhanced2

− stave_group_attn (MultiheadAttention) removed from each DecoderLayer
− stave_group_norm (LayerNorm) removed from each DecoderLayer
~ num_system_queries: 16 → 10
