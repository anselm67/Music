Noter Training Log

Architecture diagrams, training curves, and results for the staff-image → token transcription model.

The noter model is an encoder-decoder Transformer. The encoder reads a cropped staff image (64×768 px, grayscale) and produces patch embeddings; the decoder autoregressively generates a sequence of Kern tokens, each with up to 8 simultaneous chord notes. Dataset: PDMX subset with ≤2 staves/system (System2.csv). Metric: per-token accuracy (ignoring PAD).

basic

2026-05-21 · milestone: milestone/basic-noter-staffer · 12 epochs · D=256

First functional noter model. Staff images are treated as fixed width — no variable-width padding mask. Chord slots use SIL (silence token) as padding. Reaches 95.71% token accuracy, converging around epoch 10.

enhanced

2026-05-22 · 12 epochs · D=256

Introduces variable-width source handling: real staff widths are passed to make_src_padding_mask so the encoder ignores padding patches beyond the actual image content. Also filters instrument annotation tokens from the vocabulary to reduce noise. Despite these improvements, accuracy regressed slightly — the variable-width masking changes the learning problem enough that the model needed more epochs or other changes to recover.

Changes from basic

+ Variable-width source padding mask (make_src_padding_mask from actual pixel widths)
+ Instrument annotation tokens filtered from vocab
+ NoterDataModule with proper source width tracking

Slight regression: 95.71% → 94.26%. Variable-width masking is the right approach but training starts from scratch with a harder, more realistic task. Epoch 0 accuracy (33%) is much lower than basic (85%) — the distribution shift is significant.

enhanced2

2026-05-22 · 12 epochs · D=256

Major batch of improvements, all landing on the same day. Positional embeddings are added to both the encoder (patch positions) and decoder (target sequence positions and chord-slot positions). The SOS token mismatch in inference is fixed. Dataset doubled. The combined effect is a large jump: 94% → 99%.

Changes from enhanced

+ Positional embedding + LayerNorm in SourceEmbedding (encoder input)
+ Positional embedding + LayerNorm in TargetEmbedder (decoder input)
+ Chord-slot positional embedding in TargetEmbedder
~ SIL token restored as dedicated chord-slot padding (replaces PAD)
~ Fix SOS token mismatch in greedy predict
~ Dataset doubled (train_len × 2)

enhanced3

2026-05-23 · 12 epochs · D=256

Single targeted fix: the non-standard AdamW eps=1e-4 introduced in an earlier session is removed, restoring PyTorch's default of 1e-8. The smaller epsilon allows the optimiser to take more aggressive steps in low-gradient regions, noticeably improving convergence speed and final accuracy.

Changes from enhanced2

~ AdamW eps: 1e-4 → 1e-8 (PyTorch default)
